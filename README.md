# Skills

我自己在用的 Agent Skills 集合。每个技能都是标准的 `SKILL.md` 技能包，WorkBuddy AI、Codex、Claude Code 等支持该格式的工具都能直接装。

## 技能清单

| 技能 | 一句话 | 依赖 |
|---|---|---|
| [`logopilot`](#logopilot) | 品牌 Logo 生成工作流：从参考图提炼方向，手写 SVG 出方案与交付包 | Python 3.8+；出 PNG 需 Chrome |

## 目录结构

每个技能一个顶层目录，目录名与 `SKILL.md` 里的 `name` 字段严格一致（这是硬要求，装的时候靠它对上）：

```
.
├── README.md
├── logopilot/
│   ├── SKILL.md             入口：流程、约束、红线
│   ├── agents/openai.yaml   Codex / ChatGPT 桌面端界面元数据
│   ├── assets/              技能图标
│   ├── references/          分阶段参考文档
│   ├── scripts/             脚本（纯标准库）
│   └── templates/example/   跑得通的完整范例
```

## 安装

技能目录必须严格是 `<skills-root>/<技能名>/SKILL.md`，**且要整个文件夹一起拷**——技能内部的脚本和文档靠相对路径互相引用，只拷 `SKILL.md` 会让后续步骤跑不起来。

```bash
git clone https://github.com/overseax/skills.git
cd skills
```

### WorkBuddy AI

```bash
mkdir -p ~/.workbuddy-ai/skills
cp -R logopilot ~/.workbuddy-ai/skills/logopilot
```

（放进 `<项目>/.workbuddy-ai/skills/` 则是项目级，只对该项目生效。）

### Codex

```bash
mkdir -p ~/.codex/skills
cp -R logopilot ~/.codex/skills/logopilot
```


## logopilot

**品牌 Logo 生成工作流。把「分析参考 → 提炼方向 → 出方案 → 挑选 → 调字体 → 调配色 → 定稿 → 整理文件」固定成一条 8 阶段流水线。**

### 它解决什么

没有它的时候，每次做 logo 都要重新解释一遍"先分析参考图、再给方向、别一上来就定稿"，而且模型很容易退化成"一个蓝色的圆 + 一个字母"。装上之后你只需要准备三样东西：品牌名、行业、几张喜欢的参考图（参考图可选）。

### 核心工程决策：手写 SVG，不用位图生成模型

位图转矢量必然产生"锚点过多、路径不干净"的问题——这正是这类工作流最常见的翻车点。而字母类、几何类 logo 本来就该由几何构造直接生成。所以 logopilot 用代码手写干净的 SVG，文字部分也尽量画成路径以摆脱字体依赖。

好处是实打实的：锚点数量自己定、几何干净、能出真正的 16px favicon（位图缩到 16px 只会糊成一团）。

### 输出什么

- **16:9 四宫格方案图**（1672×941，2×2 标准网格）——第一眼评审物。四个方案按**实测墨迹包围盒**做光学等大，不会出现"有的胖有的瘦"
- **4 个差异化的设计方向**，附方向对比板 HTML
- **可直接编辑的 SVG**：每个方向 5 个变体（图形 / 主标志 / 单色黑 / 反白 / 字标）
- **多尺寸 PNG + favicon 套图**，以及针对细节型方向的小尺寸简化版
- **配色方案对比矩阵**（浅底 + 深底成对输出）
- **品牌规范卡与交接说明**，含已知限制

### 一个不太一样的地方：先黑白，后彩色

四宫格的主输出是**纯黑白**，彩色版是附带的。这不是审美偏好，是判据：**形状不过关的 logo 在彩色版里会被颜色救回来，在黑白版里立刻露馅。**

配色也是**品牌级而不是方向级**的——四套配色在四个方向上都过一遍，如果某一套在某个方向上塌了，那是这套配色的明度关系有问题，不是"这个方向不合适"。

### 怎么用

装好后直接说人话就能触发：

> 帮我做个 logo，品牌名「XX」，行业「XX」，这是我喜欢的参考图：<图片>

也可以显式点名：`$logopilot`（Codex CLI / IDE）或 `/logopilot`。

**注意：它不会一口气跑到定稿。** 技能内有 8 个强制停靠点，每个阶段结束都会停下来等你确认，阶段 4 必须由你挑 1–2 个方向才继续。其中阶段 0 会先搜一遍品牌名（查有没有同名同行业的公司或商标），有命中会主动告诉你并问你有没有关联——**不替用户判断这是负债还是资产**。

### 边界

不生成位图 logo、不伪造客户案例与商标授权、不承诺"能注册商标"或"专业设计师水准"、不替代设计师终审。用到系统字体时会提示交付前需转曲或换成已获商用授权的字体。

### 依赖

Python 3.8+（脚本**只用标准库**，不需要 `pip install` 任何东西）。出 PNG / favicon 需要 Chrome、Chromium、Edge 或 Brave 之一，会自动探测，找不到时可用 `CHROME_PATH` 指定。没有浏览器时 SVG、方向板 HTML、配色板 HTML 都不受影响。

包内 `templates/example/` 是一套跑通的完整范例（演示品牌 Orbit，20 个 SVG + meta.json），**可以真跑**，卡住的时候直接对照。
